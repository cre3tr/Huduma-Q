# Security

> Last verified 2026-11-04 against `84cbcf3`.

## Reporting

This is a personal project of Ian (Cre3tr). Please report suspected
vulnerabilities **privately** to the repository owner through GitHub (a private
security advisory on this repository, or a message to the owner), and not in a
public issue.

## Supported versions

Only the current `main` branch, as deployed at <https://huduma-q.vercel.app>,
is maintained. It is a hackathon demonstration; please do not submit real
personal data to it.

The internal security state of this project is tracked privately by the owner.
